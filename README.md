# Лабораторная работа №1 – 3 задания
* Задание 1.1: вычисление площади треугольника по значениям трёх его сторон
* Задание 1.2: перевод значения расстояния из одной единицы измерения в другую

# Среда программирования
Программы написаны на языке программирования Python. Для разработки использовалась среда программирования PyCharm.
# Инструкция по работе
1. Открыть файл 1 через компилятор или среду разработки и запустить проект.
   * Ввести значения трёх сторон треугольника поочередно.
2. Открыть файл 2 через компилятор или среду разработки и запустить проект.
   * Ввести поочерёдно три значения: номер изначальной единицы измерения, номер желаемой единицы измерения, значение расстояния в изначальной единице измерения.
   * Для повтора перезапустить проект.
2. Открыть файл 3 через компилятор или среду разработки и запустить проект.
   * Ввести год, который необходимо проверить на то, високосный ли он.
